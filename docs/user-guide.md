# Ear Trainer 使用指南

> 面向使用者的功能操作说明，与当前版本界面同步。后续将同步至网页内的帮助页。

## 快速开始

- **打开即用**：纯前端应用，无需注册登录；所有音频由浏览器实时合成。
- **首次点击解锁声音**：浏览器要求用户交互后才允许发声——进入任意页面后先随便点一下（如「播放题目」「试听」），之后声音即正常。
- **调音需要麦克风**：使用调音器时浏览器会请求麦克风权限，需在 **HTTPS** 环境下访问。
- **数据存本地**：设置、测试记录、手稿都保存在浏览器 `localStorage` 中，清除浏览器数据会一并丢失。

## 页面导航

底部共 4 个 Tab：

| Tab | 内容 |
|-----|------|
| 测试 | 音感测试（音名 / 音程 / 和弦）+ 节奏测试 |
| 大厅 | 训练场 🎼 · 调音 🎚️ · 演奏 🎹 三个子区块 |
| 个人中心 | 记录、评级、考察范围配置 |
| 设置 | 主题、音色、播放方式、节奏与测试参数 |

- 「测试」页右上角可在 **音高 🎵 / 节奏 🥁** 两个子功能间切换。
- 「大厅」页顶部可切换 **训练场 / 调音 / 演奏** 三段。
- 切换 Tab / 子区块不会丢失当前进度与状态，切回即可继续。

## 测试

### 音感测试（音名 / 音程 / 和弦）

1. 选择题型：**音名** · **音程** · **和弦**（页首标签）。
2. 选择玩法：
   - **标准**：固定题量（在「设置 → 测试参数」中调整）；
   - **限时**：倒计时内连续作答（时长可在设置中调整）；
   - **无限**：不限题量，自由作答，随时手动结束。
3. 点击 **▶ 播放题目** 聆听，然后从选项网格中点选答案。
4. 每题作答后立即显示对错反馈与正确答案，并自动进入下一题；拿不准可随时点 **🔁 重播** 再听一次。
5. 结束后查看成绩单；记录自动写入个人中心。

### 节奏测试

1. 切换到「节奏 🥁」域。
2. 应用会播放一个由预制节奏型组合成的完整小节（播放一遍、无参照拍）。
3. 从带记谱预览的选项中选出你听到的节奏组合。

> 节奏的音色与速度（BPM）在「设置 → 节奏」中配置。

## 大厅

### 训练场 🎼

自由聆听练习区，不计入记录。

**音高域**
1. 选定根音：音名 + 八度（八度范围 C2–C6）。
2. 点击任意 **音程** 或 **和弦** 卡片即时发声聆听；未选择时点击只播放根音。

**节奏域**
1. 点击 **音符值** 按钮（全音符 / 二分 / 四分 / 八分 / 十六分 / 附点 / 三连音…）依次拼接到当前节奏；
2. 总时值不超过一个 4/4 小节，超出时对应按钮自动禁用；
3. 支持 **撤销末尾音符** 与 **清空重来**，随时点 **播放** 试听拼好的节奏（记谱实时预览）。

### 调音 🎚️

1. 右上角选择模式：**吉他**（6 弦 E2–E4）/ **尤克里里**（4 弦 G4–A4）/ **自定义音**。
2. （吉他/尤克里里）目标弦卡片中：
   - 点 **弦名** 固定为判定目标（再点取消固定，恢复自动识别最近的弦）；
   - 点 **试听** 播放该弦标准音作参照。
3. （自定义音）选定音名与八度作为目标，可试听。
4. 点击 **开始检测** 授权麦克风，然后弹奏琴弦或哼唱：
   - 页面实时显示识别到的音名与频率；
   - 指针表指示偏差方向：**偏低 −50 ← 0 准 → +50 偏高**；
   - 文字提示「偏高 / 偏低 N 音分」，误差 **小于 10 音分** 时显示绿色「准」。
5. 离开调音页面或切换子区块时麦克风自动关闭。

### 演奏 🎹

步进网格编辑器：纵轴 = 音高，横轴 = 时间，默认 4 小节。界面分三块：**顶部状态栏 · 左侧音轨栏 · 中间网格 + 手稿栏**（窄屏时手稿栏自动移到音轨正下方）。网格始终等比铺满可用宽度。

**状态栏（从左到右）**
| 控件 | 说明 |
|------|------|
| 拍号 | 4/4 或 3/4；切换会清空当前网格（可撤回） |
| BPM | 预设 60–240 一键选，或直接输入（60–240 自动归界） |
| 最小分度 | 1/8 或 1/16，决定一格代表多短音符；来回切换精确换算，半格位置不丢 |
| 起点 | 显示当前播放起点（格），「↺ 复位」回到开头 |
| ▶ 播放 | 从起点起播；播放中变为 ⏸ 暂停 / ⏹ 停止，暂停后为 ▶ 继续 |
| 💾 保存 | 有未保存修改时亮起，保存到手稿 |
| ↶ ↷ | 撤回 / 恢复（仅限网格音符编辑） |

**网格操作**
- **放置音符**：在空白格按下即创建音符，松开前横向拖动可拉长时值；创建后立即发出该音（当前轨音色）便于核对。
- **删除音符**：点击已有音符所在格即移除。
- **设置起点**：点击网格顶部的小节编号，播放将从该处开始。
- 网格左侧为音高标签列（按「个人中心 → 黑键显示方式」呈现升号或降号）。

**音轨栏**
- **新增音轨** / **删除音轨**：多声部分轨编辑；网格只显示并编辑当前选中轨。
- 每条音轨可选 **音色**（复用节奏测试音色池）并可独立 **静音**。
- 点击音轨 **色块** 试听该轨音色（A4 参考音）。

**手稿栏**
- **新建**：生成空白手稿并立即出现在列表中（默认名「新建手稿-N」自动顺延不重号）；有未保存修改时会先确认。
- **保存**：把当前编辑内容写入激活的手稿；未激活任何手稿时保存会新建一条。
- **加载**：点击列表项载入；若有未保存修改会先确认。
- **重命名 / 删除**：列表项右侧按钮；删除不可恢复。
- 手稿上限 **10 条**，超出时请先删除再新建。

## 个人中心

- **统计卡**：参与次数 · 平均准确率 · 当前评级（音乐新手 → 进阶学习者 → 熟练乐手 → 音乐达人 → 大师级）。
- **最近记录**：最近 10 局的题型 / 玩法 / 得分，可一键清空全部记录。
- **考察配置**（对测试生效）：
  - **根音区间**：低音区 C3–B3 / 中音区 C4–B4 / 高音区 C5–B5 / 全音域 C3–C6；
  - **单音考察**：白键（自然音）或全键（含升降号）；
  - **黑键显示方式**：升号（C#）或降号（Db），全局影响所有界面的展示；
  - **音程考察 / 和弦考察**：勾选想练的范围；一项都不勾时视为全部启用。

## 设置

| 分组 | 可调项 |
|------|--------|
| 页面风格 | 黑夜·青 / 明亮日间 / 黑夜·紫 / 黑夜·琥珀 共 4 主题 |
| 音色类型 | 正弦波 / 三角波（默认）/ 方波 / 锯齿波 / 电子 FM，作用于测试与训练场乐音 |
| 播放方式 | 同时播放（和声效果）或逐音上行（旋律效果） |
| 节奏 | 节奏音色（打击鼓 或 5 档 A4 乐音）· 速度 BPM 60–200（预设 + 自定义） |
| 测试参数 | 标准模式题量 · 限时模式时长 |

> 所有设置即时保存；测试参数的修改对**下一局**生效。

## 常见问题

**没有声音？**
先在页面上任意点击一次以解锁音频（浏览器自动播放策略）；再检查设备静音与音量。

**调音器无法开始检测？**
麦克风权限需要 **HTTPS** 安全环境（`localhost` 除外）；请在浏览器弹窗中允许麦克风，或在浏览器站点设置里手动授权后重试。

**演奏页切拍号后音符不见了？**
切换 3/4 ↔ 4/4 会清空当前网格，属预期行为；立即点状态栏 **↶ 撤回** 即可恢复。

**换设备/清缓存后数据没了？**
所有数据仅存于当前浏览器本地，暂无云同步；重要手稿请留意备份计划（导出功能开发中）。
